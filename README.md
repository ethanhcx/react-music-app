# Side A — Music Archive

A React music app built from the Intro to React exercise. It showcases Drake albums, and lets you like or unlike each album.

## Run locally

```sh
npm install
npm run dev
```

## Project structure

- `src/main.jsx` mounts the app.
- `src/App.jsx` owns the album list and form state.
- `src/components/` contains one folder per component, each with an `index.jsx` file, and a barrel `index.jsx` for exports.
- `src/App.css` contains the app styles.

Album and artist details are hard-coded for this exercise; no API is used.
